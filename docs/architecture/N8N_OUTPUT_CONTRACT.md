# N8N Output & Input Schema Contract
## Luxera Provenance Integration Specification

---

## 1. Overview

This document specifies the exact interface contract between the **Luxera Provenance Platform** (Next.js Application Gateway) and the **n8n Source of Wealth Compliance Engine**. All requests and responses MUST strictly conform to these TypeScript interfaces and JSON Schema specifications.

---

## 2. Inbound Webhook Payload (Luxera $\rightarrow$ n8n Engine)

### Endpoint: `POST /api/v1/sow/evaluate`

```typescript
export interface SoWEvaluationRequestPayload {
  /** Unique execution tracking identifier generated by Luxera */
  case_id: string;
  
  /** Tenant organization identifier for multi-tenant isolation */
  organization_id: string;
  
  /** User ID of the compliance officer or agent submitting the case */
  submitted_by_user_id: string;
  
  /** Declared wealth metadata provided by data subject during onboarding */
  declared_wealth: {
    primary_source_category: 'EMPLOYMENT' | 'BUSINESS_OWNERSHIP' | 'INVESTMENTS' | 'INHERITANCE' | 'REAL_ESTATE_SALE' | 'OTHER';
    declared_annual_income: number;
    currency: string; // ISO 4217 code, e.g. "MYR", "USD", "EUR"
    employer_or_business_name: string;
    occupation_title?: string;
  };

  /** Collection of supporting document reference objects */
  supporting_documents: Array<{
    document_id: string;
    document_type: 'PAYSLIP' | 'BANK_STATEMENT' | 'TAX_DECLARATION' | 'AUDITED_FINANCIALS' | 'LEGAL_DEED' | 'OTHER';
    file_url: string; // Secure short-lived presigned URL
    file_mime_type: 'application/pdf' | 'image/png' | 'image/jpeg';
    document_hash_sha256: string;
  }>;

  /** System evaluation options */
  options: {
    enable_pii_redaction: boolean;
    confidence_threshold: number; // e.g. 0.85
    strict_financial_rules: boolean;
  };
}
```

## 3. Outbound Callback Payload (n8n Engine $\rightarrow$ Luxera)

### Endpoint: `POST /api/v1/sow/webhook/callback`

```typescript
export interface SoWEvaluationResponsePayload {
  case_id: string;
  organization_id: string;
  workflow_execution_id: string;
  processed_at: string; // ISO 8601 UTC timestamp

  /** Final compliance decision */
  overall_decision: 'APPROVED' | 'MANUAL_REVIEW_REQUIRED' | 'REJECTED';
  
  /** Calculated composite risk score (0 to 100) */
  composite_risk_score: number;
  risk_level: 'LOW' | 'MEDIUM' | 'HIGH' | 'CRITICAL';

  /** AI Extracted Structured Financial Profile */
  extracted_financial_profile: {
    verified_monthly_income: number | null;
    verified_annual_income: number | null;
    detected_employer_name: string | null;
    total_bank_deposits_detected: number | null;
    deposit_evaluation_period_months: number | null;
    currency_code: string;
    extraction_confidence_score: number; // 0.0 to 1.0
  };

  /** Results of deterministic rule evaluations */
  rule_evaluation_results: Array<{
    rule_id: string; // e.g. "RULE_SALARY_VS_DEPOSIT_RATIO"
    rule_name: string;
    passed: boolean;
    severity: 'INFO' | 'WARNING' | 'CRITICAL';
    observed_value: string | number;
    expected_threshold: string | number;
    failure_message?: string;
  }>;

  /** Compliance & Anomaly Flags triggered */
  compliance_flags: Array<{
    flag_code: string; // e.g. "CRITICAL_INCOME_DEPOSIT_MISMATCH", "UNVERIFIED_THIRD_PARTY_DEPOSITS"
    flag_title: string;
    description: string;
    risk_points_added: number;
    recommended_remediation: string;
  }>;

  /** Full execution provenance and auditing data */
  provenance_metadata: {
    n8n_version: string;
    llm_model_used: string; // e.g. "gpt-4o"
    tokens_consumed: number;
    execution_time_ms: number;
    payload_sha256: string;
  };
}
```

## 4. Error Payload Specification

In the event of processing failures (e.g. OCR unreadable, corrupt PDF, LLM timeout), the n8n engine MUST return the following structure:

```typescript
export interface SoWEvaluationErrorPayload {
  case_id: string;
  organization_id: string;
  error_code: 'OCR_EXTRACTION_FAILED' | 'LLM_TIMEOUT' | 'SCHEMA_PARSING_ERROR' | 'UNSUPPORTED_DOCUMENT_FORMAT' | 'INTERNAL_WORKFLOW_ERROR';
  message: string;
  details?: Record<string, unknown>;
  failed_at: string; // ISO 8601
  retryable: boolean;
}
```
