# Typography System & Font Licensing

## Primary Font Family: Switzer

Luxera Provenance utilizes the **Switzer** grotesque sans-serif font family as its core enterprise visual brand standard.

- **Designer:** Jérémie Hornus
- **Publisher:** Indian Type Foundry / Fontshare
- **Version:** Complete Static & Variable Font Suite
- **Location:** `/public/Switzer_Complete/Fonts`
- **EULA:** Fontshare Free Font End User License Agreement (FF EULA) (`/public/Switzer_Complete/License/FFL.txt`)

### Licensing & Usage Rights

- **Permitted Uses:** Personal and commercial use across all digital platforms, web interfaces, print media, and embedded electronic applications.
- **Redistribution Notice:** Local font files located at `/public/Switzer_Complete/Fonts/WEB/fonts/` serve as the single source of truth for the Luxera Provenance web application. No CDN dependencies or external Google Fonts calls are used.
- **Self-Hosting Compliance:** All `@font-face` declarations reside within `/app/globals.css` referencing local assets directly to enforce air-gapped security and privacy compliance.
