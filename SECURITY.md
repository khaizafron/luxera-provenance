# Security Policy

## Reporting Security Vulnerabilities
If you discover a security vulnerability or potential PII leak, please send an encrypted email to `security@luxera.internal`. Do not open public GitHub issues for security reports.

## Architecture Security Principles
- Pre-LLM PII Tokenization
- Envelope Encryption for Document Storage
- Cryptographic SHA-256 Hash Chained Audit Ledger
- Row Level Security (RLS) for Multi-Tenancy Isolation
